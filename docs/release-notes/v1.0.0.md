# v1.0.0 — release notes

**Published on 2026-09-15.** The [release](https://github.com/kuotunyu/bev-calibration-lab/releases/tag/v1.0.0)
is bound to commit `59dce9d46317a36b9e2346ea29d1ff980a2a829d`.
CI, Pages, package checksums, independent installation and explorer interaction
acceptance completed. See the [verification record](../verification/publication-and-interchange.md).
Subsequent documentation updates do not change the tagged source or frozen artifacts.

## Known issues found after release

Three reading notes, written after the release from the frozen evidence, are in
[v1.0.0 known issues](../errata.md): identity recovery at ±0.25° is a floating-point
boundary artifact, the timing stress carries no information, and far-range BEV
means are dominated by grazing rays. No released number, figure or tag changes.

## Research evidence already retained

The [formal evidence set](../evidence/README.md) retains calibration sensitivity,
paired comparisons, recovery, timing, and exclusions. The
[analysis reproduction record](../verification/analysis-reproduction.md) binds
the original evaluation producer, analysis policy, and two byte-identical
analysis outputs. Preparing this release does not rerun training or replace
those observations.

The [experiment card](../experiment-card.md) states the development,
calibration, and locked evaluation roles; the [model card](../model-card.md)
states preprocessing, units, pretrained identity, and limitations. Identity,
classical, and each learned seed remain visible. The fixed-three-seed mean is
not a prediction ensemble. Zero-fault degradation, unsupported estimates, and
unresolved causes of weak recovery must remain in the result interpretation.

## Presentation

The Chinese primary README and English overview lead to the same scientific
contracts. The [offline explorer](../demo/calibration-explorer.html)
uses first-party synthetic plane geometry, fixed observations, and declared
single-axis levels. It embeds Plotly.js with its copyright and MIT notice;
it uses no nuScenes pixels, checkpoint, or network service. Local analytic tests
and deterministic generation do not replace browser interaction acceptance.

## Publication checks

The formal registry, report and both observed figures were reproduced twice from
the original evidence. The real descriptive distribution export and consumer
interoperability checks also passed. See the [publication verification
record](../verification/publication-and-interchange.md) for source identities,
digests and scope; interoperability does not demonstrate an AEB benefit.

The repository gate, built-package checks, offline explorer acceptance, final
version/source identity, package hashes and public-data guard were verified for
the release. The [mutation audit](../verification/mutation-audit.md) preserves
the terminal base campaign and named amendment checks separately; no fresh full
final-revision mutation campaign is claimed.

The package does not distribute sensor data or model weights. Repository
licensing does not replace the data and pretrained-weight licenses. Results
are a controlled calibration study, not detector performance, deployment
qualification, or real-vehicle safety evidence.
